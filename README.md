STUDENTS DROPOUT PREDICTION

OVERVIEW
Formal education is an important process every individual must go through. However, we have cases of dropouts, and this has been a concern in our society. And on the other hand, schools,especially private, want to have the best students in their register. To balance this has been a major issue in today education system and society as a whole.
Therefore, this project builds a machine learning model to predict if a student will dropout or not. This helps schools cater or pay more attention and put in place the right measures to enable students scale through different hurdles in this process/perform better in class.And this mitigate the risk dropouts pose in our society. This project serves school authorities and the society at a time.

🎯 OBJECTIVES
-Predict student dropout using historical data
-Build a clean model
-Evaluate model using robust metrics
-Reduce the dense population of dropouts in the society which is the genesis of some crimes
-Helps to reaccess measures that aid students productivity in school and society.

🚀 Features
-EDA
-Data preprocessing pipeline
-Feature engineering (categorical encoding, scaling)
-Model training (Logistic Regression, Decision Tree )
-Class imbalalance Techniques,GridSearchCV
-Model evaluation ( Precision, Recall, F1-score)
